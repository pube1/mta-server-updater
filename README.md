# MTA:SA 64-Bit Sunucu Güncelleyici

Multi Theft Auto (MTA:SA) Windows 64-bit sunucularını [nightly.multitheftauto.com](https://nightly.multitheftauto.com/) üzerinden en güncel sürüme tek tıkla güncelleyen otomatik araç.

## Özellikler
- **Otomatik Sürüm Bulma:** Nightly sayfasından en güncel `mtasa_x64-1.6-rc-*.exe` linkini otomatik tespit eder.
- **Sessiz İndirme & Ayıklama:** Kurulum programını arkaplanda indirir ve taşınabilir 7-Zip ile ayıklar.
- **Modern Windows Gezgini:** Klasör seçimi için Windows Gezgini arayüzünü kullanır.
- **Güvenli Güncelleme:** Yalnızca `MTA Server64.exe` ve `x64/` klasörünü günceller; `deathmatch`, `acl.xml`, `mtaserver.conf` ve resource dosyalarınıza dokunmaz.
- **Hatırlama:** Sunucu klasörünüzü bir kez seçtikten sonra sonraki güncellemelerde otomatik hatırlar.

## Kullanım
1. Projeyi indirin veya klonlayın.
2. `Guncelle.bat` dosyasına çift tıklayın.
3. Sunucunuzun kurulu olduğu klasörü seçin.
